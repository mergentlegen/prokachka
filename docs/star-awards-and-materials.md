# Награды, материалы и иконка приложения

Перед развёртыванием этой версии выполните в Supabase SQL Editor файл
`supabase/star-award-kinds-migration.sql`. Миграция повторяемая, ничего не удаляет.
Затем обновите код сервера, выполните `npm ci`, `npm run build` и перезапустите
приложение обычным способом. Дополнительные секреты и изменения cron не нужны.

## Проверка

- Выдайте тестовому участнику Starter, затем Premium: рейтинг увеличится на **4**.
- История показывает название каждой новой награды, автора, дату и комментарий.
  Старые награды не переименовываются, включая прежние выдачи по 4–5 звёзд.
- Отмена конкретной выдачи вычитает только звёзды этой записи.
- Вставьте YouTube-ссылку в задание, шаг программы или объявление. Под описанием
  участник увидит обложку и кнопку. В редакторах также есть предварительный просмотр.
- Другие сайты представлены карточкой с доменом и заметной кнопкой. Произвольные
  сайты сервер не загружает: закрытые ссылки не передаются сторонним сервисам
  превью. При ошибке загрузки YouTube-обложки ссылка остаётся доступной.
- На iPhone удалите старый ярлык и добавьте сайт на домашний экран заново.
  Проверьте золотой знак на тёмно-синем фоне и название «Прокачка».
- `/manifest.webmanifest`, `/apple-icon`, `/brand-icon`, `/brand-icon-small`
  должны возвращать manifest/PNG без авторизации.

Автономный офлайн-режим не добавлен: для работы приложения нужен интернет.
