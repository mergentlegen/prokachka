# Готовые программы

## Что добавлено

В панели наставника в разделе «Программы» появился каталог «Готовые программы». Сейчас в нём доступна «Мечта с планом» — адаптированная React-игра с помесячным сравнением двух путей, итоговым экраном и финальным вопросом.

Готовая программа публикуется одной кнопкой. Её шаг создаётся как `evergreen`: у него нет дедлайна, а доступ ограничивается той же командой или веткой сети, которая указана для обычной программы. Повторная публикация в одной команде не создаёт дубликат благодаря частичному уникальному индексу.

Игра не начисляет мили из браузера. Кнопка «Отправить результат» становится доступной только после прохождения игры и правильного ответа на финальный вопрос, затем используется существующий защищённый Telegram-процесс и обычная проверка наставником. Это не позволяет клиентскому коду самостоятельно подделывать начисление.

## Обновление существующей базы

Перед выкладкой кода один раз выполните в Supabase SQL Editor файл:

```text
supabase/20260925-ready-programs.sql
```

Не запускайте поверх рабочей базы `schema.sql` или `bootstrap.sql`. Миграция добавляет `template_key`, `interactive_kind`, уникальность готовой программы внутри команды и обновлённую RPC `app_create_program`. После успешного выполнения можно выкладывать код и перезапускать Next.js.

Если база новая и создаётся через `psql`, `supabase/bootstrap.sql` уже подключает эту миграцию последней. В SQL Editor файл `bootstrap.sql` целиком не вставляйте: он содержит команды `\ir`.

## Проверка после деплоя

1. Откройте панель наставника с правом публикации и перейдите в «Программы».
2. В блоке «Готовые программы» нажмите «Опубликовать программу».
3. Участником из доступной команды откройте вкладку «Программы» и запустите «Мечта с планом».
4. Пройдите 12 месяцев, выберите правильный ответ и убедитесь, что только после этого появляется возможность отправить результат.
5. Проверьте, что программа отображается без срока и не появляется второй раз при повторном нажатии наставником.
