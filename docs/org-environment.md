# Временная игра «Ұйым ортасы: Миль жарысы»

Игра добавлена в каталог готовых заданий. Публикация ручная: наставник открывает «Программы» → «Готовые задания» и нажимает «Добавить в задания». Аудитория соответствует ветке публикующего наставника.

Перед публикацией в Supabase SQL Editor последовательно выполнить `supabase/20261014-org-environment.sql` и `supabase/20261015-org-environment-batch.sql`. Если первый файл уже применён, достаточно второго. Повторное выполнение второго безопасно.

Игра состоит из 10 вопросов с таймером, 15 факторов сортировки и 45-секундного блица. Переходы и промежуточные мили считаются в браузере без сетевых запросов. Ход на этом устройстве сохраняется в `localStorage`, чтобы пережить обновление страницы. Смена устройства или очистка данных браузера может сбросить несохранённый ход; уже завершённый результат остаётся в базе.

По кнопке «Нәтижені сақтау» клиент отправляет протокол ответов один раз. Сервер сверяет порядок вопросов, ответы, диапазоны времени и пересчитывает мили. Затем в одной транзакции создаётся принятая работа и завершённая попытка. Повторная отправка возвращает прежний результат, не заменяя его. Точную скорость каждого ответа сервер не может независимо подтвердить без запросов во время игры — это осознанный компромисс ради плавного интерфейса.

По окончании однодневной публикации сначала нажать «Убрать из заданий», затем при необходимости откатить кодовый релиз. Откат кода не отменяет SQL-миграции и не удаляет заработанные мили или историю.
