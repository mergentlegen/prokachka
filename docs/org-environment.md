# Временная игра «Ұйым ортасы: Миль жарысы»

Игра добавлена в каталог готовых заданий. Публикация остаётся ручной: наставник открывает «Программы» → «Готовые задания» и нажимает «Добавить в задания». Публикация верхнего наставника видна всей команде; публикация участника с правом публикации — его ветке.

До публикации один раз выполните `supabase/20261014-org-environment.sql` в SQL Editor проекта Supabase. Миграция расширяет предел хранения миль до 15 900, добавляет новый тип игры и серверный подсчёт. Повторное выполнение безопасно. Обычные задания по-прежнему ограничены 100 милями через API.

В игре 10 вопросов с таймером, 15 факторов для сортировки и 45-секундный блиц. Неверные ответы и истечение времени не перезапускают игру. Каждый ход и промежуточный счёт сохраняются сервером; после завершения результат записывается один раз. При перезагрузке страницы участник продолжает текущий раунд.

Для завершения однодневной публикации сначала нажмите «Убрать из заданий» в каталоге, затем при желании откатите кодовый релиз. Откат кода не отменяет SQL миграцию и не удаляет заработанные мили или историю участников. Это соответствует правилу неизменяемого результата.
